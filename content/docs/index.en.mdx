## Introduction

Welcome to the OpenClaw remote deployment documentation. This guide will help you deploy and configure OpenClaw on a remote server and connect various messaging channels.

## Channel Integration

- [Discord](/docs/discord) — DMs and server text channels via the official Discord bot gateway
- [Feishu (Lark)](/docs/feishu) — Connect to Feishu/Lark bot via WebSocket long connection; DMs and groups
- [Telegram](/docs/telegram) — DMs and groups via grammY; long polling or webhook
